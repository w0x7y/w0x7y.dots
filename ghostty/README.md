# ghostty, w0x7y special

my [ghostty](https://ghostty.org) config. [rime](https://github.com/w0x7y/rime) colors and maple mono

### install

needs ghostty and the [maple mono nf](https://github.com/subframe7536/maple-font) font. made on ghostty `1.4`

```sh
git clone https://github.com/w0x7y/w0x7y.dots
cp -r w0x7y.dots/ghostty ~/.config/
```

### what's in it

~ rime colors from `themes/rime`, rime's ghostty port, unedited\
~ maple mono nf at size 18\
~ the background is 80% opaque, so the wallpaper shows through a little\
~ 5 points of padding, balanced so leftover space spreads evenly around the text\
~ a desktop notification when a command finishes while ghostty isn't focused

### layout

```text
config.ghostty   font, padding, opacity and notifications
themes/rime      rime's colors
```
